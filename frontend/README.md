# Frontend — dealer dashboard

Next.js 16 (App Router, plain JS, client-rendered pages + Tailwind) implementing
the dashboard areas from spec section 3, wired directly to the FastAPI backend.

## Setup

```bash
cd frontend
npm install
cp .env.local.example .env.local   # point NEXT_PUBLIC_API_URL at your backend
```

## Run

```bash
npm run dev
```

Requires the backend running and reachable at `NEXT_PUBLIC_API_URL` (CORS is
open on the backend for local dev — see `backend/app/main.py`).

## Pages

| Route | Spec dashboard area | Backend calls |
|---|---|---|
| `/` | Executive funnel | `GET /metrics/funnel` |
| `/leads`, `/leads/[id]` | Live lead queue | `GET/PATCH /leads`, slots, follow-ups, escalation question intake |
| `/inventory` | ERP inventory | `GET /projects` (stale/blocked units shown greyed out) |
| `/salespeople` | Salesperson board | `GET /salespeople` |
| `/slots` | Slots and bookings | `GET /projects/{id}/slots`, hold/confirm/cancel |
| `/followups` | Follow-up centre | `GET /follow-ups/due`, `POST /leads/{id}/follow-up` |
| `/escalations` | Escalation centre | `GET/PATCH /escalations` |
| `/quality` | Quality and operations | `GET /quality-reviews` |

## Notes

- Every page is a client component (`"use client"`) fetching directly from the
  browser — no server-side data fetching, kept deliberately simple for a demo.
  A production build would move reads to Server Components.
- Next.js 16 makes dynamic route `params` a Promise even in client components
  (unwrapped with React's `use()` in `app/leads/[id]/page.js`) — worth knowing
  if you're used to Next 14 conventions.
- `AGENTS.md`/`CLAUDE.md` in this directory are auto-regenerated by `next dev`
  itself (Next.js 16's built-in agent-rules file) — don't hand-edit them, and
  don't be surprised when they reappear after deleting them.
- Verified end-to-end with a headless-Chromium script against a live backend +
  seeded throwaway Postgres: all 8 pages render real data with zero console
  errors, the stale PRJ008 unit shows correctly blocked in ERP Inventory, and
  the "Ask a question" flow on a lead detail page round-trips through
  classification to a created escalation ticket.
